# Mubdev Image Assets Directory

## Portrait Asset Replacement Instructions

As specified in the Master Instructions:
- **Status**: The current portrait is a temporary placeholder.
- **Rule**: Do not invent a permanent portrait representing Mubarek Hussein.
- **Replacement Procedure**:
  1. Once Mubarek provides his official photograph, place it here (e.g., `mubarek-portrait.png` or `mubarek-portrait.webp`).
  2. Recommended dimensions: `480px × 580px` (or 2x retina `960px × 1160px`), with transparent or dark background matching the midnight/navy color palette.
  3. Update the export reference in `src/data/brandConfig.js` or the Hero portrait component.

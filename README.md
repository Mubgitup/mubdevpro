# Mubdev — Personal Brand Website

> Personal brand website of **Mubarek Hussein** — Third-year Software Engineering student at Haramaya University & Aspiring Full-Stack Developer.

## Tech Stack
- **Frontend**: React 19, JavaScript (ESNext), CSS3 (Modern Variables & Glassmorphism)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Build System**: Vite

## Getting Started
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
